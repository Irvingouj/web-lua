# web

## OVERVIEW

Notebook UI — Preact + Vite + CodeMirror 6. Single-page app with a Jupyter-style cell interface.

## STRUCTURE

```
.
├── src/
│   ├── main.tsx            # App bootstrap (Vite entry)
│   ├── App.tsx             # Root Preact component
│   ├── components/         # UI components (8 files)
│   ├── hooks/              # Custom Preact hooks
│   ├── types/
│   │   └── generated.ts    # ts-rs generated types (do not edit)
│   ├── styles.css          # Single global CSS (17KB)
│   ├── notebook.ts         # Demo data (could be in data/)
│   └── showcase.ts         # Demo data (could be in data/)
├── tests/
│   ├── e2e/                # 18 Playwright spec files
│   ├── helpers.ts          # Cell manipulation helpers
│   └── extension-helpers.ts# Extension test helpers
├── public/                 # Chrome extension assets (non-standard)
│   ├── manifest.json
│   ├── background.js
│   └── content-script.js
├── scripts/
│   └── copy-ext-assets.js  # Copies extension assets to public/
├── index.html              # Vite HTML entry
├── vite.config.ts          # Vite config with monorepo aliases
├── playwright.config.ts    # E2E config (sequential, Chromium only)
├── tsconfig.json           # TS strict, bundler resolution
├── package.json            # Preact + CodeMirror + Playwright
└── .gitignore
```

## WHERE TO LOOK

| Task | Location |
|------|----------|
| Modify UI / layout | `src/components/*.tsx` |
| Modify editor | CodeMirror integration in components |
| Modify notebook state | `src/hooks/` |
| Add E2E test | `tests/e2e/*.spec.ts` (numbered test names) |
| Modify types | `src/types/generated.ts` — **DO NOT EDIT** (generated by ts-rs) |
| Modify styles | `src/styles.css` (single global file) |

## CONVENTIONS

- **Preact** (not React): `preact` ^10.29.2
- **CodeMirror 6** for editor: `@codemirror/*` packages
- **Biome** for lint/format: 2-space indent, no `any`, no `!`
- **Vite aliases**: `@pi-oxide/web-lua` → `../crates/web-lua/js/index.ts`
- **Test helpers**: `data-testid` selectors for UI automation
- **Numbered tests**: `test("1: app loads", ...)` for sequential ordering

## ANTI-PATTERNS

- **Single global CSS**: `src/styles.css` (17KB) instead of component-scoped CSS
- **Demo data at `src/` root**: `notebook.ts` and `showcase.ts` should be in `src/data/` or `src/fixtures/`
- **Extension assets in public/**: `manifest.json`, `background.js`, `content-script.js` are Chrome extension files mixed with web app assets
- **No `favicon.ico` or images**: `public/` only contains extension assets
- **Tests run sequentially**: `fullyParallel: false` in Playwright config

## NOTES

- Dev server: `npm run dev` (port 5173)
- E2E tests auto-start dev server on port 5174
- `web/scripts/copy-ext-assets.js` copies from `crates/extension-lua/js/` to `public/`
- `vite.config.ts` resolves `@pi-oxide/*` to `../crates/*/js/index.ts` (not npm packages)
